# 🎓 Study Group Finder - Backend

Backend API for the Study Group Finder platform built using:

⚡ Node.js  
⚡ Express.js  
🗄️ PostgreSQL  
💬 Socket.io  
☁️ Render Deployment  

---

## 🌐 Live Backend

👉 http://study-group-backend-b1kf.onrender.com/

---

## ✨ Features

- 🔐 Authentication (Login / Register)
- 👤 Student Profile Management
- 🤖 AI Group Recommendations API
- 💬 Real-time Chat using Socket.io
- 📅 Study Schedules API
- 📚 Notes Upload System
- 📊 Dashboard Statistics API

---

## 🛠️ Tech Stack

- Node.js
- Express.js
- PostgreSQL
- Socket.io
- Multer (file uploads)
- CORS
